# 伴走コンサル（仮称）LP

公開URL：`https://www.basic-fnb.com/consulting/`

| 場所 | 役割 | 公開 |
|---|---|---|
| `_consulting/config.json` | サービス名・色・実績数値・自社店舗の事例・店舗・FAQ・Googleフォーム・GA などの設定 | されない |
| `_consulting/src/` | ページのテンプレート・CSS・JS・画像 | されない |
| `_consulting/build.py` | 上の2つから `/consulting/` を生成 | されない |
| `consulting/` | **生成物**。直接編集しない | される |

`_` で始まるフォルダは GitHub Pages で公開されません。

## 更新のしかた

```
python3 _consulting/build.py
```

`config.json` か `src/` を編集したら、必ず実行してから commit します。
サービス名・数字・FAQ・店舗などは `config.json` だけを直せば、本文・タイトル・構造化データ・llms.txt に反映されます。

## 問い合わせフォーム（Googleフォーム）

`config.json` の `google_form_url`（公開用の viewform URL）を埋め込んでいます。
フォーム側で設定しておくこと：

- [ ] 「設定 > 回答 > メールアドレスを収集」を「回答者からの入力」にし、「回答のコピーを回答者に送信」を「常に表示」に（受付確認メールの代わり）。設定後、重複する「メールアドレス」の質問は削除
- [ ] 「回答」タブ > 「新しい回答についてのメール通知を受け取る」をオン（通知先は編集者のアカウント）。複数人に届けたい場合はスプレッドシートにリンクして共有
- [ ] 「運営店舗数」は記述式 → プルダウン（1店舗／2〜3店舗／4〜6店舗／7〜10店舗／11店舗以上）にすると集計しやすい
- [ ] 「プライバシーポリシーに同意する」の説明欄に https://www.basic-fnb.com/privacy のリンクを入れる
- [ ] 送信後の確認メッセージに、返信の目安を入れる（例：「通常1営業日以内にご連絡します」）
- [ ] フォームのタイトルはLPの見出しと重複するので、「無料相談のお申し込み」など短くしてもよい

## 計測（GA4）

`page_view` に加えて、次のイベントを送信します。

| イベント | タイミング | パラメータ |
|---|---|---|
| `cta_click` | 相談ボタンのクリック | `cta_position`（header / fv / how / pricing / sticky / form_newtab） |
| `form_view` | Googleフォームの読み込み | — |
| `form_success` | Googleフォームが2回目に読み込まれた（＝送信後の完了画面） | — |
| `faq_open` | FAQ を開いた | `question` |

埋め込みフォームの中の入力は取得できないため、`form_success` は iframe の再読み込みで推定しています（1ページのフォームなら送信時のみ発生）。
GA4 の管理画面で `form_success` をキーイベントに設定してください。正確な件数はフォームの回答数で確認します。
Google 広告を使う場合は `ads_conversion_send_to`（例：`AW-XXXX/XXXX`）を設定します。
UTM などの流入元は GA4 が自動で記録します。

## 正式公開の手順

1. 下の「公開前の確認事項」をすべて確定
2. `config.json` の `noindex` を `false` にしてビルド
3. ルートの `sitemap.xml` に `https://www.basic-fnb.com/consulting/` を追加
4. Google Search Console で URL 検査 → インデックス登録をリクエスト
